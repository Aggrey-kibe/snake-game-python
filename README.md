# Snake Game — Python (Pygame)

## Overview
This project is a fully functional Snake Game implemented in Python using the Pygame framework.  
It demonstrates real-time game loops, event handling, collision detection, and state management.  
The project emphasizes clean structure, readability, and correct game logic — making it suitable for portfolio or technical review.

---

## Features
- Real-time keyboard input handling  
- Dynamic snake movement and growth logic  
- Collision detection (walls and self)  
- Score tracking system  
- Game-over state handling  
- Structured game loop with frame rate control  

---

## Technical Stack
- **Language:** Python 3  
- **Framework:** Pygame  
- **Paradigm:** Event-driven programming  

---

## Project Structure
- `snake_game.py` – Contains the full game logic:
  - Initialization of Pygame and screen setup  
  - Snake movement and growth  
  - Food spawning and collision detection  
  - Score and level system  
  - Game-over handling  

> Note: The full Python script is in `snake_game.py`. It is separated from the README for clarity and professional presentation.
